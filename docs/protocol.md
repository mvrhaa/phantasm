# Zero protocol reference

Protocol version **1**, Zero 0.1.0. Generated by `scripts/gen_protocol_docs.py` from `src/zero/protocol/messages.py`; do not edit by hand. The design behind it is in section 6 of `ZERO_SPEC.md`.

## Connecting

- WebSocket at `ws://127.0.0.1:47400/ws`, on the loopback interface only.
- The local token goes in the header `Authorization: Bearer <token>` (or `?token=` while debugging); `zero token` prints it. A wrong token closes the socket with `4401`.
- Every message is a JSON object with a `type`. A message that expects an answer carries an `id`; the answer points back at it with `reply_to`.
- The first message is `hello`. An unknown `type` gets an `error` with `unknown_type`; the connection stays open.
- Events of a turn go to every connected client, so all of them show the same.

## Client → Zero

### `hello`

First message of a connection; sending it again updates the declaration.

| Field | Type | Default |
|---|---|---|
| `id` | string | `null` |
| `reply_to` | string | `null` |
| `protocol` | integer | required |
| `client` | [ClientInfo](#clientinfo) | required |

```json
{
  "type": "hello",
  "id": "h-1",
  "protocol": 1,
  "client": {
    "app": "desktop",
    "client_id": "desktop-macbook",
    "display_name": "Desktop on MacBook",
    "character": {
      "name": "Zero",
      "persona": "A calm, curious companion.",
      "poses": [
        "idle",
        "sit",
        "wave"
      ],
      "moods": [
        "neutral",
        "happy",
        "sad"
      ]
    },
    "environment": "macOS desktop app; replies show in a chat window that renders Markdown",
    "actions": [
      {
        "name": "screenshot",
        "description": "Capture the user's screen",
        "input_schema": {
          "type": "object",
          "properties": {
            "display": {
              "type": "integer"
            }
          }
        },
        "policy": "allow",
        "timeout_s": 15.0
      }
    ]
  }
}
```

### `session.rewound`

A session went back to just before a user message (or, on a dry run, would). `text` is that message, for the input. Gone: `removed_messages` messages, `removed_todos` todo items and `removed_session_memories` entries of the conversation's memory added since, the agents it started since. `files` were put back as they were; a file changed outside Zero since is left alone. `kept` counts the calls whose effects stay, by tool. Every client gets it after a real rewind and should load the history again.

| Field | Type | Default |
|---|---|---|
| `id` | string | `null` |
| `reply_to` | string | `null` |
| `session_id` | string | required |
| `message_id` | string | required |
| `text` | string | required |
| `dry_run` | boolean | `false` |
| `removed_messages` | integer | `0` |
| `files` | array of [FileUndo](#fileundo) | `[]` |
| `removed_todos` | integer | `0` |
| `removed_session_memories` | integer | `0` |
| `stopped_agents` | array of string | `[]` |
| `kept` | object | `{}` |

```json
{
  "type": "session.rewound",
  "reply_to": "rw-1",
  "session_id": "s-1",
  "message_id": "msg-12",
  "text": "Now write it to notes.md",
  "dry_run": false,
  "removed_messages": 6,
  "files": [
    {
      "path": "/Users/me/notes.md",
      "change": "restored"
    }
  ],
  "removed_todos": 0,
  "removed_session_memories": 0,
  "stopped_agents": [],
  "kept": {
    "run_command": 1
  }
}
```

## Shared objects

### ContentPart

One item of content: a [TextPart](#textpart), an [ImagePart](#imagepart) or a [FilePart](#filepart), told apart by `type`.

### TextPart

A piece of plain text.

| Field | Type | Default |
|---|---|---|
| `text` | string | required |

### ImagePart

An image passed inline as base64.

| Field | Type | Default |
|---|---|---|
| `mime` | string | required |
| `data_b64` | string | required |

### FilePart

A file referred to by its name and path; `mime` tells an image from other files.

| Field | Type | Default |
|---|---|---|
| `name` | string | required |
| `path` | string | required |
| `mime` | string | `null` |

### ClientInfo

How a client introduces itself in `hello`.

| Field | Type | Default |
|---|---|---|
| `app` | string | required |
| `client_id` | string | required |
| `display_name` | string | `null` |
| `character` | [Character](#character) | `null` |
| `environment` | string | `""` |
| `actions` | array of [ActionDecl](#actiondecl) | `[]` |

### Character

The character a client shows: its persona and what it can express. Without poses and moods the character shows no expressions: the model gets no `set_expression` and answers in one step.

| Field | Type | Default |
|---|---|---|
| `name` | string | required |
| `persona` | string | `""` |
| `poses` | array of string | `[]` |
| `moods` | array of string | `[]` |

### ActionDecl

An action the client can perform; Zero offers it to the model as a tool.

| Field | Type | Default |
|---|---|---|
| `name` | string | required |
| `description` | string | required |
| `input_schema` | object | `{}` |
| `policy` | `"allow"` \| `"ask"` \| `"deny"` | `"ask"` |
| `timeout_s` | number | `15` |

### Attachment

A file sent along with a user message, either inline or as a local path.

| Field | Type | Default |
|---|---|---|
| `name` | string | required |
| `mime` | string | required |
| `data_b64` | string | `null` |
| `path` | string | `null` |

### MessageCommand

How to run one turn: extra instructions, whether the model gets tools, which model. The instructions go into the system prompt of this turn only; `name` is kept with the user's message so a client can label it in the history.

| Field | Type | Default |
|---|---|---|
| `name` | string | required |
| `instructions` | string | `""` |
| `tools` | `"all"` \| `"none"` | `"all"` |
| `model` | `"main"` \| `"small"` | `"main"` |

### SessionInfo

What clients are told about a session. `kind` keeps the user's chats apart from the sessions of agents and schedules.

| Field | Type | Default |
|---|---|---|
| `id` | string | required |
| `title` | string | `null` |
| `updated_at` | ISO 8601 time | required |
| `kind` | `"chat"` \| `"agent"` \| `"scheduled"` | `"chat"` |

### AgentRef

Which agent something belongs to.

| Field | Type | Default |
|---|---|---|
| `id` | string | required |
| `name` | string | required |

### AgentInfo

What clients are told about an agent.

| Field | Type | Default |
|---|---|---|
| `id` | string | required |
| `name` | string | required |
| `parent_session_id` | string | required |
| `session_id` | string | `null` |
| `task` | string | required |
| `status` | `"working"` \| `"asking"` \| `"waiting_user"` \| `"done"` \| `"failed"` \| `"stopped"` | required |
| `report` | string | `null` |
| `created_at` | ISO 8601 time | required |
| `updated_at` | ISO 8601 time | required |

### HistoryMessage

A stored message as returned by `history.ok`.

| Field | Type | Default |
|---|---|---|
| `id` | string | required |
| `turn_id` | string | `null` |
| `role` | `"user"` \| `"assistant"` \| `"tool"` | required |
| `content` | array of [ContentPart](#contentpart) | required |
| `status` | `"ok"` \| `"cancelled"` \| `"error"` | `null` |
| `source` | `"desktop"` \| `"phone"` \| `"scheduler"` \| `"agent"` | `null` |
| `command` | string | `null` |
| `created_at` | ISO 8601 time | required |

### ToolRun

A finished tool call as returned by `history.ok`.

| Field | Type | Default |
|---|---|---|
| `call_id` | string | required |
| `turn_id` | string | required |
| `tool` | string | required |
| `label` | string | `""` |
| `input` | object | `{}` |
| `status` | `"ok"` \| `"error"` \| `"denied"` \| `"cancelled"` | required |
| `summary` | string | `""` |
| `output_preview` | string | `""` |
| `duration_ms` | integer | `0` |
| `created_at` | ISO 8601 time | required |

### TodoItem

One item of a session's todo list.

| Field | Type | Default |
|---|---|---|
| `number` | integer | required |
| `text` | string | required |
| `status` | `"pending"` \| `"in_progress"` \| `"done"` | `"pending"` |

### ExpressionState

A pose and a mood of the character.

| Field | Type | Default |
|---|---|---|
| `pose` | string | required |
| `mood` | string | required |

### Usage

Tokens spent by a turn.

| Field | Type | Default |
|---|---|---|

| `output_tokens` | integer | `0` |
